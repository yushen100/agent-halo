# agent-halo 改动历史（2026-10-31 ~ 11-01）

> 2026-11-01 由 Claude 依据会话记录重建（原文件丢失）。按时间顺序记录每轮“用户反馈 → 改动”，参数以当时为准；**当前状态以 `HANDOVER.md` 为准**，这里只用于追溯“为什么是这样”。

## 起点（交接前）
- 呼吸只作用球壳、内部神经网固定；环自转 `ringSpin`；频谱柱；外扩波纹；22 项单测。

## 10-31
1. **色彩收口**：去掉核心光晕偏蓝、子任务青绿、矩阵绿/紫；失败改灰，红色只给审批。抽出 `ringAngle()`。新增上下文水位弧、工具耗时弧（对数刻度 1/10/60s）。
2. **频谱柱被压短**：布局预留柱高，R 最多让 14%；修 SYS/TOK 叠字、分隔线横穿柱子。
3. “还是好丑”：神经网冷热分层（只有最近 90s 亮）；所有柱子改细柱 + 亮帽。
4. 继续降噪：环活动段宽晕收窄、TOOL 大字辉光减弱、底部面板细线化、空路由格只画小点。
5. 参考 B 站 BV1jgpB68EtG：**事件卡带**（环内厚带，每卡一个事件）+ **外射光线**（长度=耗时/输出 token）。
6. 织网质感：每条关系延长成贯穿球体的淡弦。
7. 光线律动：出膛生长 + 光包流动 → 用户要求“和真实事件关联” → 光包改为同工具/同模型事件触发。
8. 光线全面事件化：`raySpec` 按事件类型定线型/根数（连续调用次数）/粗细（上下文占用）；淡出改为“被同类后续事件顶替一次暗一档”；环外波纹从自己的卡片位置发出（`fxAngle`）。
9. 波纹改细（两端渐隐 `taperArc`）→ 用户“线条都好细”→ 全面加粗。
10. 参考 B 站 BV1dhn163E2V（haloflux 作者）：**节拍驱动变速自转**（每事件角冲量 τ900ms）+ 光柱运动拖影；光柱加粗；暂停时 TOK/SEC 数字仍变的 bug 修复。
11. 底部面板被控制条遮住：canvas `flex:1 1 0; height:0`。底部面板动效（arrive 缓动）；事件矩阵取窗口错误修复。
12. 参考 haloflux 电脑版：**巨环偏左出屏构图** + 光柱通道 + 卡带微型仪表 + **底部八格**（新增事件流水/上下文/耗时轨迹/工具状态）。
13. 网络路由恒为 0：normalize 的 Claude 分支没接 `classifyNetwork`、分类器不认 `WebFetch` → 修复；新增 `start-halo.cmd`。
14. 巨环第二轮：光柱改水平、卡片放正、裁掉遥测台背后的环、去掉顶部波形横穿。

## 11-01
15. “好卡”：面板尺寸缓存（不在帧内读布局）、事件列表 `content-visibility`、光柱贴图化、神经网分桶描边。环带重做为小仪表卡 + 内外梳齿 + 弧内亮线束；顶部指标栏。
16. “不能贴合弧形”（看 haloflux 源码思路）：**径向条带**（离屏渲染每条，按角度旋转贴到环带）。
17. 最大化仍不贴合 / 灰：条带裁进圆环；扫描贴图高反差 + 最近邻；粗细随新旧变化。
18. 光柱改为**沿条带半径方向延长**（与卡片严丝合缝），矢量 1px 线；环带/卡片纯黑底白字。
19. 最大化不要球：织网**摊平**铺满弧内（`webProject`）。
20. 太卡 + 右侧太空：限帧、背景缓存、织网长弦解析裁剪 + 离屏缓存；光柱至少射出 70% 宽度。
21. 指标栏与环重叠 → 顶部独立 62px 指标栏；帧率自适应；去灰。
22. **灰蒙蒙根源**：CSS 全屏颗粒层/扫描线/暗角三层叠加 → 全部停用；所有背景纯黑。
23. 光柱“长出来”（动画时钟 1.1s 生长、纤维错开）；不限帧（跟随 120Hz）；遥测台八格轮流绘制。
24. 环外波纹多层、分色（模型金/工具青绿/返回浅青绿/回声白），model.end 与 tool.result 也发波。
25. 下拉框卡顿（聚焦时降帧）；波纹传得更远。
26. 织网“活动少”：**级联传导**（上游 3 跳）。
27. 网络线换色（下载黄绿/上传橙/搜索粉/代理紫/网关浅金）。
28. 空闲呼吸摆动 `idleSway`（卡带 ±0.9° 后加大到 ±2.6°）；外圈刻度改纯匀速（=时间）。
29. 1× 回放环会僵住 → 呼吸按“卡带是否在推进”触发；卡带多事件同时到达改为像素累加平滑推入；遥测台过渡按真实时间。
30. **多环差速** `drawDiffRings`（逆转环 ∝ token/s、虚线环工具运行 ×3、点阵环等人几乎停）；小环模式也加。
31. 呼吸摆动不受暂停影响（唯一例外，用 performance.now）。
32. 右下角状态读数 `drawCornerReadout`；去底框。
33. 底部八格高对比 `boostCtx`（灰→白、透明度抬高）。
34. 锐度：撤销大画布 DPR 限 1；画布物理像素 1:1。
35. 网络流线加粗加亮。
36. 光柱律动（呼吸慢波 + 节拍）；加粗；线条只长出/缩回不凭空出现；**发散**而非汇聚；三色 → 以白为主（约 1/6 点缀色）；小图光柱光晕也改白；“不要改波”。
37. 光柱稀疏 + 再加粗（亮线 7px / 暗线 5px / 间距 12px）。
38. 织网绕竖轴地球仪自转（曾误画线框球，已撤）。
39. 底部八格卡片化；事件流水彩色动词；耗时轨迹面积图；事件矩阵热力格。
40. 相位段名 / 停滞 / 审批在巨环模式落到画面外 → 先移到可见处，后**全部合并进右下角读数**。
41. 点击画布事件 → 跳到该事件并暂停。
42. **中英切换**（`I18N` + `STATIC_EN`），不混排；“空白压缩”说明。
43. 右下角读数重排版、收紧间距。
44. 交接文档重写为“当前状态”版；本历史文件为流水账。
